# 🎨 Static Webpage Design

A clean and responsive static webpage developed using **HTML5** and
**CSS3** as part of the **DecodeLabs Frontend Development Industrial
Training Program (Batch 2026)**.

## 📖 About the Project

This project focuses on building a well-structured and visually
appealing static website using semantic HTML and modern CSS. It
demonstrates the fundamentals of frontend development, including webpage
structure, styling, and responsive design principles.

## ✨ Features

-   Semantic HTML5 structure
-   Clean and modern UI
-   Responsive layout
-   Organized CSS styling
-   Smooth user experience
-   Cross-browser compatible

## 🛠️ Technologies Used

-   HTML5
-   CSS3
